# Ideas box

Ideas arrive unfinished. Left in the head, they either fade or keep circling, taking up thinking budget without growing. Written down, even as three rough words, they stay safe and can develop on paper. The box takes everything, and nothing has to be ready.

Load the Clear Head config: `~/.clear-head/config.md`, a "Clear Head config" document in the person's connected notes or docs, or the project instructions. Use it for where the box lives (an ideas list in storage, or a project or list in the tool). If it's missing, capture into the conversation and offer clear-head-setup.

## Capture

1. Write the idea down **in the person's own words**, with today's date, exactly as rough as it is. Leave evaluating, polishing and turning it into a task for the review.
2. If the person adds a thought to an idea that's already in the box, append it under that idea with the date. Ideas grow by layers.
3. Confirm in one line and get back to what the person was doing.

## Review

Run this every once in a while. The config sets the rhythm; monthly, with the reflection, is the default.

1. Load the box. Start with the ideas touched least recently: they're the ones the head has stopped carrying.
2. For each idea, read it back and ask what's new. Has anything about it changed since it was written? Is it still alive for the person? An idea grows only with the person's own thoughts: to open it up, ask ("What would it look like? Who is it for? What's the smallest version?") and record their answers.
3. Decide:
   - **Grow**: add the person's new thought and keep it in the box.
   - **Act**: it's ready. Turn it into a task or a project with a first step, using the task-rewriter rules, and move it out of the box.
   - **Let go**: it's no longer interesting. Delete it, or move it to an archive section if the person likes keeping a history.
   - **Leave**: nothing new. It stays as is; ideas often need several rounds.
4. Keep the pace easy, and let the person skip ideas or stop at any point. Note in the journal where the review stopped, so the next one picks up there.

Done when every idea reviewed has one of the four outcomes applied.
