# So that what?

Tasks get on the list for all sorts of reasons. This question links what's on the list to what the person actually wants, which surfaces cheaper routes, work that serves nothing, and wants nobody is working on.

Your part is the questions. The answers, the other routes and the decision all come from the person; when they're stuck, try a different question.

## Up: from a task to a want

1. Read the task and ask, "So that what?" The answer is its nearest result.
2. Ask again about that result, and keep going until you reach something the person wants for its own sake, or "I don't know".
3. With the chain in view, ask:
   - "How else could you get that?" A shorter route often appears.
   - "Does this task still serve it?"
4. Decide: keep, change (often a better first step), or drop.

Two guardrails:
- Most tasks are maintenance, like paying rent or buying milk. Let those be; forcing a chain onto them wastes the person's time.
- "I don't know" is a fine answer and not a verdict. Plenty of things that changed someone's life started as a task with no clear why. Decide after thinking, never by rule.

## Down: from a want to a task

1. Ask the person to list their **wants**: what they'd like to have, finish or achieve in the foreseeable future. These don't need to be grand life goals; that kind of certainty is rare and unnecessary.
2. For each want, check whether at least one task on the list moves toward it.
3. A want with no task is a wish, and nothing will happen to it. For each one, the person chooses one of:
   - add a first step, worded with the task-rewriter rules
   - consciously park it for now

## For a project

When the whole project is in question, ask these in order:
- What is it, in one sentence?
- So that what?
- What else has to happen for that result to arrive?
- What happens if it isn't done, and how much does that matter?
- Who will use the result, and how?
- How else could the same "so that what" be reached?

Close with a short map: each want with the tasks serving it, tasks that serve no want (fine unless they're heavy), and wants with no tasks. Done when each examined item has a decision: keep, change, drop, park, or a new first step.
